# Week 1: Full-Stack Application on Azure Kubernetes Service (AKS)

This project demonstrates a production-ready Full-Stack application deployed on Azure Kubernetes Service (AKS) with OIDC Authentication and HTTPS.

## Documentation

Please refer to the detailed documentation in the `docs/` folder:

*   **[Architecture & Structure](docs/architecture.md)**: Overview of the technology stack, backend patterns, and project folder structure.
*   **[Deployment Guide](docs/deployment.md)**: Step-by-step instructions for setting up Azure resources, installing cluster controllers, building images, and applying Kubernetes manifests.
*   **[Authentication](docs/authentication.md)**: Details on the Hybrid Authentication flow using OpenID Connect and the BFF pattern.
*   **[Testing](docs/testing.md)**: Comprehensive test cases for infrastructure, API, frontend, authentication, security, and performance.
