# Week 2 Submission: Metrics & Monitoring

## Project Summary
For Week 2, the application was enhanced with robust production (Microsoft Azure) and product (Google Analytics) monitoring. The system is now capable of detecting failures in real-time and alerting the administration team immediately.

## Key Accomplishments
- **Full-Stack Monitoring**: Integrated App Insights (Backend) and GA4 (Frontend).
- **Hardened Telemetry**: Manual request tracking ensures 100% reliable error reporting in ESM environments.
- **Automated Alerting**: Configured Azure Alerts to trigger email notifications on critical failure thresholds.
- **Verification Tools**: Built-in Dashboard test button for easy auditor verification.
